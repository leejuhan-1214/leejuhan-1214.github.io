# 이과전선

[게임 플레이](https://leejuhan-1214.github.io/math/) · [실제 3D 보스 보기](https://leejuhan-1214.github.io/math/bosses.html) · [GLB 모델 다운로드](https://leejuhan-1214.github.io/math/boss-models.zip)

5개 챕터 · 40개 스테이지. 각 챕터의 마지막 단계에는 수식으로 몸체와 무기를 구성한 보스가 전용 지형에서 등장합니다. 수학 기호와 수식의 획을 직접 입체로 만들었습니다.

- ∇ 빙하 관측자: ∇·`f(x)=1/x`·`x^-1` 몸체와 ∇·∫ 창. 긴 창, 얼음탄, 빙하 파동. ∂로 얼음탄 반사.
- ∫ 용광로 집행자: Σ·`∫f(x)dx` 몸통, = 화구와 ∫ 대검. 대검, 흡입 화염탄, 화염 파동. 흡입 중 폭발 수식으로 역공.
- Δ 뇌전 절단자: Δ·`lim(x)` 몸체, √ 칼날·다리와 Δ·+ 꼬리. 지그재그 돌진, 전도 기둥, 교차 낙뢰. 두 기둥을 맞혀 낙뢰 역류.
- Σ 폭풍 포격자: Σ 포구, `sin(x)`·`cos(x)` 날개와 0·+ 터빈. 공중 포격, 이동 회오리, 폭격. 포격 중 후방 추진 핵 공략.
- Ω 공리 붕괴자: Ω·`f(g(x))` 핵과 `sin(x)`·`cos(x)`·`x^2`·`1/x` 궤도. 두 종류의 수식 무기를 동시에 전개. 앞선 보스의 공략법을 조합해 궤도 중단.

일반 탄환도 모든 보스에게 피해를 줍니다. 공략 성공 시 추가 피해와 경직이 적용됩니다.

다운로드한 GLB는 형상·재질·애니메이션을 모두 포함해 단독으로 불러올 수 있습니다. 원본 모델 코드는 `boss-models.js`와 `formula-mesh.js`를 함께 사용합니다.

모바일: 왼쪽 스틱 이동 · 화면 드래그 조준 · 흰 버튼 연사 · 점프/⇢/∂/∫/lim · f(x) 편집 · ⛶ 전체화면.

체력 100 · 탄약 최대 100. 훈련 메뉴에서 보스 단계를 바로 선택할 수 있습니다.
